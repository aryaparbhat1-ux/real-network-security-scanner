# NetShield - Automated Network Security Assessment Tool

A Python-based automated network security scanner designed for Kali Linux to perform fast host discovery, port scanning, and automated risk reporting using real-time background infrastructure checks.

## Features
- **Host Discovery:** Scans subnet dynamically via back-end tools.
- **Port Enumeration:** Maps open service gates on targeted infrastructure.
- **Automated Reporting:** Generates clean markdown risk logs inside the `reports/` folder.

## Quick Installation & Usage

```bash
# 1. Clone the repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git

# 2. Navigate to directory
cd YOUR-REPO-NAME

# 3. Run the assessment tool
sudo python3 net_assess.py
```
